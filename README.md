# Asignaci-n-de-recursos-en-la-nube-Cloud-Resource-Allocation-
Asignación de tareas a servidores en la nube que minimiza a la vez el tiempo de respuesta (makespan) y el consumo de energía. Compara un algoritmo genético, un PSO discreto y un híbrido GA-PSO contra un baseline voraz en 3 escenarios con 30 corridas, pruebas de Wilcoxon y análisis de sensibilidad. Implementado en Python.
